# Landing Page - Soluciones Digitales a tu Medida

Página web corporativa y de captación de clientes desarrollada con tecnologías web estándar (**HTML5, CSS3 y JavaScript Vanilla**). Su objetivo es presentar servicios de desarrollo web y automatización administrativa, permitiendo a los clientes filtrar soluciones y solicitar cotizaciones directamente vía WhatsApp.

## Características Principales

* **Diseño Responsivo (Mobile-First):** Adaptación fluida a dispositivos móviles, tablets y pantallas de escritorio mediante CSS Grid y Flexbox.
* **Filtrado Dinámico de Servicios:** Clasificación interactiva en tiempo real por categorías (*Desarrollo Web*, *Automatización*, *Análisis y Gestión*) sin recargar la página.
* **Validación de Formulario en Tiempo Real:** Verificación de campos obligatorios antes del envío con retroalimentación visual inmediata.
* **Integración Directa con WhatsApp:** Construcción automática de URL (`wa.me`) con los datos estructurados del cliente listos para iniciar la conversación comercial.
* **Cero Dependencias Externas:** Código ligero y optimizado para tiempos de carga instantáneos.

## Tecnologías Utilizadas

* **HTML5:** Etiquetas semánticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) y atributos de accesibilidad (`aria-label`).

* **CSS3:** Variables nativas (`:root`), CSS Grid, Flexbox, `backdrop-filter` y diseño adaptable con `@media` queries.

* **JavaScript (ES6+):** Manipulación del DOM, manejo de eventos, validación de formularios y codificación de parámetros URL (`encodeURIComponent`).
